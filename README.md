# Digital Clock

## Features
- Displays current time in hours, minutes, and seconds
- On and off button
- Updates every second
- Simple, clean interface

## Notes
- This project is a basic web-based digital clock example
- Works in modern browsers with JavaScript enabled
- Includes `index.html`, `style.css`, and `script.js`

## How to Run
1. Clone this repo and locate `digital-clock` files
2. Open `index.html` in your web browser
3. Or serve the folder with a local web server
4. The clock will start automatically when the page loads
